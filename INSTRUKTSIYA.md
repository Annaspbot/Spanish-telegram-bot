# Пошаговая инструкция: как запустить бота (для новичков)

Эта инструкция рассчитана на то, что вы **никогда не работали с Python и терминалом**.
Идём строго по шагам, ничего не пропускаем.

---

## Шаг 0. Что вообще нужно

У вас должна быть папка с файлами бота (`bot.py`, `database.py`, `seed_db.py`,
`spaced_repetition.py`, `requirements.txt`, `README.md`, папка `data` с двумя
файлами внутри). Скачайте все эти файлы себе на компьютер в **одну папку**,
например, назовите её `spanish_bot` и положите на Рабочий стол.

Важно: файл `verbs.py` и `vocab.py` должны лежать **внутри подпапки `data`**,
рядом с остальными файлами — то есть должно быть так:

```
spanish_bot/
├── bot.py
├── database.py
├── seed_db.py
├── spaced_repetition.py
├── requirements.txt
├── README.md
└── data/
    ├── verbs.py
    └── vocab.py
```

Если при скачивании файл `verbs.py` или `vocab.py` попал не в папку `data`,
а рядом с `bot.py` — создайте папку `data` внутри `spanish_bot` и перетащите
эти два файла туда.

## Шаг 1. Установить Python

Python — это язык программирования, на котором написан бот. Его нужно
установить один раз.

### Если у вас Windows:
1. Зайдите на сайт: https://www.python.org/downloads/
2. Нажмите большую жёлтую кнопку "Download Python 3.x.x"
3. Запустите скачанный файл (обычно называется `python-3.xx.x-amd64.exe`)
4. **ОЧЕНЬ ВАЖНО:** в самом низу окна установки поставьте галочку
   **"Add python.exe to PATH"** (или "Add Python to PATH") — без этого ничего
   не заработает
5. Нажмите "Install Now" и дождитесь окончания установки
6. Нажмите "Close"

### Если у вас Mac:
1. Зайдите на сайт: https://www.python.org/downloads/
2. Скачайте версию для macOS и установите как обычную программу
   (двойной клик → Продолжить → Продолжить → Установить)

### Проверка, что Python установился:
Откройте терминал (см. Шаг 2, там написано как) и введите:
```
python3 --version
```
(на Windows можно попробовать `python --version`)

Если в ответ появилась строка вида `Python 3.11.5` — всё установилось.
Если пишет "command not found" / "не является внутренней командой" —
Python не установился правильно, попробуйте установить заново и не забудьте
галочку "Add to PATH".

## Шаг 2. Открыть терминал (командную строку)

Терминал — это чёрное (или белое) окошко, куда вводятся текстовые команды
вместо кликов мышкой. Дальше всё будем делать через него.

### Windows:
1. Нажмите кнопку "Пуск"
2. Наберите `cmd` или `PowerShell`
3. Откройте "Командная строка" или "PowerShell" (подойдёт любое)

### Mac:
1. Нажмите Cmd+Пробел (Spotlight)
2. Наберите `Terminal`
3. Откройте приложение "Terminal"

---

## Шаг 3. Перейти в папку с ботом через терминал

Когда открыли терминал, нужно "зайти" в папку `spanish_bot`, которую вы
скачали. Это делается командой `cd` (change directory).

Например, если папка лежит на Рабочем столе:

**Windows:**
```
cd Desktop\spanish_bot
```

**Mac:**
```
cd ~/Desktop/spanish_bot
```

Если папка лежит в другом месте — путь будет другим. Самый простой способ
не ошибиться:
1. Наберите в терминале `cd ` (с пробелом в конце, не нажимайте Enter)
2. Перетащите мышкой саму папку `spanish_bot` из проводника/Finder прямо
   в окно терминала — путь подставится автоматически
3. Нажмите Enter

Проверить, что вы в нужной папке, можно командой:
- Windows: `dir`
- Mac: `ls`

Она покажет список файлов — там должны быть `bot.py`, `database.py` и т.д.

## Шаг 4. Установить нужные библиотеки

В той же папке в терминале введите:

```
pip install -r requirements.txt
```

Если Windows ругается, что `pip` не найден, попробуйте:
```
python -m pip install -r requirements.txt
```

Если Mac/Linux ругается похожим образом, попробуйте:
```
pip3 install -r requirements.txt
```

Подождите, пока команда отработает (появится много текста и в конце что-то
вроде "Successfully installed aiogram..."). Это нормально, так и должно быть.

---

## Шаг 5. Вставить токен бота

У вас уже есть токен от @BotFather (длинная строка вида
`123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ`).

Самый простой для новичка способ — вписать токен прямо в файл `bot.py`:

1. Откройте файл `bot.py` любым текстовым редактором (подойдёт обычный
   "Блокнот" на Windows или "TextEdit" на Mac — только в TextEdit сначала
   зайдите в меню Format → Make Plain Text, чтобы не испортить файл)
2. Найдите в файле строку (она в самом начале файла):
   ```
   BOT_TOKEN = os.environ.get("BOT_TOKEN", "PASTE_YOUR_TOKEN_HERE")
   ```
3. Замените `PASTE_YOUR_TOKEN_HERE` на ваш токен, не убирая кавычки.
   Должно получиться примерно так (это пример, не настоящий токен):
   ```
   BOT_TOKEN = os.environ.get("BOT_TOKEN", "123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ")
   ```
4. Сохраните файл (Ctrl+S на Windows, Cmd+S на Mac) и закройте редактор

⚠️ **Не выкладывайте этот файл с вписанным токеном никуда в открытый доступ**
(например, на GitHub в публичный репозиторий) — токен даёт полный доступ
к управлению вашим ботом.

## Шаг 6. Заполнить базу словами (один раз)

В терминале (там же, в папке `spanish_bot`) введите:

```
python3 seed_db.py
```

(если не сработает — попробуйте `python seed_db.py`)

Должно появиться что-то вроде:
```
Слова/фразы: добавлено (или уже было) 181 записей.
Глаголы: обработано 60, форм спряжения на глагол: 12 ...
Итого в базе: 181 слов/фраз, 720 форм спряжения.
```

Это значит — база создалась и заполнилась. Появится новый файл
`spanish_bot.db` в этой же папке — это и есть база данных, трогать её
руками не нужно.

---

## Шаг 7. Запустить бота

В том же терминале введите:

```
python3 bot.py
```

(если не сработает — `python bot.py`)

Если всё хорошо, в терминале появится строка вроде:
```
INFO:__main__:Бот запущен, жду сообщений...
```

**Это окно терминала нужно оставить открытым** — пока оно открыто, бот
работает. Если закроете терминал — бот выключится (это нормально для
локального теста; позже, если понадобится, чтобы бот работал 24/7 даже
при выключенном компьютере, можно перенести его на хостинг — про это
написано в конце README.md).

## Шаг 8. Написать боту в Telegram

1. Откройте Telegram
2. Найдите вашего бота (по тому username, который вы задавали при создании
   через @BotFather, например `spanish_words_anna_bot`)
3. Нажмите "Запустить" / отправьте команду `/start`
4. Дальше в боте — кнопки: "📚 Учить слова/фразы", "🔤 Тренажёр спряжений",
   "📊 Статистика"

Если бот не отвечает — вернитесь в терминал и посмотрите, нет ли там
текста красного цвета (ошибки, traceback). Скопируйте текст ошибки и
пришлите мне — разберёмся.

## Частые проблемы

**"python3: command not found" или "python: command not found"**
→ Python не установлен или не добавлен в PATH. Переустановите Python
(Шаг 1), обязательно с галочкой "Add to PATH" на Windows.

**"No module named aiogram"**
→ Шаг 4 (установка библиотек) не выполнился. Убедитесь, что вы в папке
`spanish_bot` (командой `dir` или `ls` должны быть видны файлы бота),
и повторите `pip install -r requirements.txt`.

**"Не задан токен бота"**
→ Вы не вписали токен в `bot.py` (Шаг 5), либо вписали с ошибкой
(убедитесь, что кавычки на месте).

**Бот запустился, но при нажатии кнопок ничего не происходит**
→ Проверьте, что файл `spanish_bot.db` создался (Шаг 6 выполнен), и что
терминал с ботом всё ещё открыт и не показывает ошибок.

**Хочу остановить бота**
→ Кликните в окно терминала, где он запущен, и нажмите Ctrl+C.

---

Если что-то не заработает на любом из шагов — просто скопируйте текст
ошибки из терминала и пришлите мне, разберём вместе.
