# Испанский бот — слова, фразы, сленг + тренажёр спряжений

Телеграм-бот для изучения испанского на уровне A2-B2:
- 📚 ~180 слов, фраз и разговорных выражений (включая сленг Испании) — легко расширяется
- 🔤 Тренажёр спряжений глаголов в **Pretérito Indefinido** и **Pretérito Imperfecto**
  (60 глаголов × 12 форм = 720 форм для тренировки)
- 🧠 Интервальное повторение (упрощённый алгоритм в духе Anki/SM-2) — то, что вы
  хорошо помните, будет появляться реже; то, что забываете — чаще

## Установка

1. Установите Python 3.10+ (если ещё нет).
2. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
3. Задайте токен бота (тот, что дал @BotFather) через переменную окружения:

   **Linux/macOS:**
   ```
   export BOT_TOKEN="ваш_токен_сюда"
   ```
   **Windows (PowerShell):**
   ```
   $env:BOT_TOKEN="ваш_токен_сюда"
   ```

   Либо, если не хочется возиться с переменными окружения — впишите токен
   прямо в `bot.py` вместо `PASTE_YOUR_TOKEN_HERE` (только не выкладывайте
   потом этот файл в открытый репозиторий на GitHub).

4. Заполните базу данных (один раз, при первом запуске это сделается
   автоматически, но можно и вручную):
   ```
   python seed_db.py
   ```

5. Запустите бота:
   ```
   python bot.py
   ```

6. Откройте вашего бота в Telegram → `/start`.

## Команды бота

- `/start` — главное меню
- `/learn` — режим "слова/фразы"
- `/verbs` — тренажёр спряжений
- `/stats` — статистика прогресса
- `/menu` — вернуться в главное меню

## Как это работает

**Слова/фразы:** бот показывает испанское слово → вы жмёте "Показать перевод" →
жмёте "Знаю ✅" или "Не знаю ❌" → бот планирует следующее повторение (скоро,
если не знали; через день/неделю/дольше — если знали).

**Спряжения:** бот даёт инфинитив + время (Indefinido/Imperfecto) + местоимение →
вы пишете форму текстом → бот сверяет ответ и говорит, правильно или нет.

## Как расширить базу слов/глаголов

- Слова, фразы, сленг: дописывайте кортежи `(испанский, перевод, категория, уровень, пример)`
  в списки `VERBS_INF`, `NOUNS`, `ADJECTIVES`, `PHRASES`, `SLANG` в файле `data/vocab.py`.
- Глаголы: добавьте `(инфинитив, перевод, is_irregular, level)` в `VERB_LIST` в
  `data/verbs.py`. Если глагол полностью неправильный в Indefinido — добавьте его
  формы в словарь `IRREGULAR_INDEFINIDO`; если у него меняется корень в 3-м лице
  (тип pedir/dormir) — в `STEM_CHANGING_IR_INDEFINIDO`. Все остальные глаголы
  спрягаются автоматически по стандартным правилам (в т.ч. с учётом
  орфографии `-car/-gar/-zar`).
- После изменений просто запустите `python seed_db.py` ещё раз — новые записи
  добавятся, старые дубли будут проигнорированы.
