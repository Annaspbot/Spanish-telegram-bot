# Changelog

Здесь фиксируем, что менялось в боте по версиям — чтобы не путаться,
что и когда добавили.

## v2.1 — 4 августа 2026

### Проверка ответов — умнее
- Слова с вариантами через "/" в базе (`el jefe / la jefa`, `cansado/a`,
  `profesor/profesora`) теперь принимают любой из вариантов
- Артикль (el/la/los/las/un/una) можно писать или не писать — не важно
- Проверено на всех 32 таких записях, которые уже были в базе слов

### Статистика пользователя (/stats) — расширена
- Слова и спряжения: всего / ещё не начато / изучаю / закреплено — отдельно
- Активность: тренировок завершено, правильных/почти-правильных/ошибок,
  точность, общее время в тренировках
- По дням: сколько дней занимался, лучший день, среднее в день
- Всё считается из уже собираемых данных (сессии тренировок + прогресс),
  отдельной системы XP/уровней для этого не потребовалось

### Админ-статистика — новое (/admin)
- Доступна только владельцу бота (проверка по Telegram user ID через
  переменную окружения `ADMIN_USER_ID`); для всех остальных команда
  ничего не делает и не выдаёт своего существования
- Всего пользователей, новых сегодня, активных сегодня/неделю/месяц
- Тренировок завершено всеми, среднее число заданий и время тренировки,
  общая точность
- Сколько пользователей учит слова vs тренирует спряжения

### Файлы, изменённые в этой версии
- `bot.py` — изменён
- `database.py` — изменён (добавлена колонка `finished_at` в
  `lesson_sessions` через безопасную миграцию — не ломает уже
  развёрнутую на Railway базу)
- `text_utils.py` — изменён
- `.env.example` — изменён (добавлена `ADMIN_USER_ID`)

### Нужно вручную на Railway
- Добавить переменную `ADMIN_USER_ID` в Settings → Variables

## v2.0 — 27 июля 2026

### Слова/фразы — режим переписан полностью
- Ответ теперь печатается текстом вместо кнопок "Знаю/Не знаю"
- Сравнение ответа без учёта регистра и лишних пробелов
  (`Casa` = `casa` = `CASA`, `por  favor` = `por favor`)
- Мягкая проверка ударений: `niño` → `nino` или `canción` → `cancion`
  засчитывается как "почти правильно" с подсказкой, а не как ошибка
- Прогресс-бар в каждом сообщении: "Слово 8 из 30"
- Статистика в конце урока: правильно / почти правильно / ошибок /
  точность / время
- Сессия урока хранится в SQLite (таблица `lesson_sessions`), а не в
  памяти процесса — переживает перезапуск/передеплой бота

### Навигация — новое, работает во всех режимах
- Команда `/menu` — сбрасывает любое активное состояние, показывает
  главное меню; работает всегда, из любого режима
- `/start` тоже сбрасывает активную тренировку перед показом меню
- В каждом сообщении режима обучения — три кнопки:
  ➡️ Дальше · 🏠 Главное меню · ❌ Закончить тренировку
- Механизм сброса универсальный (`register_cleanup` +
  `cancel_active_sessions` без указания режима) — новый обучающий режим
  в будущем получит эти кнопки автоматически, без отдельного кода

### Деплой на Railway
- Токен бота убран из кода, читается только из переменной окружения
  `BOT_TOKEN`
- Добавлены `Procfile`, `runtime.txt`, `.env.example`, `.gitignore`
- Путь к базе данных настраивается через `DB_PATH` — для постоянного
  хранилища через Railway Volume (иначе прогресс обнуляется при
  каждом передеплое)

### Файлы, изменённые/добавленные в этой версии
- `bot.py` — изменён
- `database.py` — изменён
- `text_utils.py` — новый файл (нормализация и сравнение ответов)
- `Procfile`, `runtime.txt`, `.env.example`, `.gitignore` — новые файлы
- `requirements.txt` — добавлен `python-dotenv`

## v1.0 — исходная версия
- Слова/фразы: показ слова → кнопка "показать перевод" →
  "Знаю"/"Не знаю"
- Тренажёр спряжений (Pretérito Indefinido, Imperfecto): текстовый
  ответ, без прогресс-бара и общей статистики
- Интервальное повторение (упрощённый SM-2)
- Локальный запуск, токен прямо в коде
